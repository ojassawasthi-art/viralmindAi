# Roadmap

## Delivered in this foundation release
- [x] Modular core and five specialist skills.
- [x] Portable setup notes for Claude, ChatGPT and Gemini.
- [x] Transparent deterministic virality-readiness scorer.
- [x] Example input and automated unit tests.
- [x] Architecture, security, scoring and contribution documentation.

## Next releases

### 0.2 — Research adapters
- Search-provider abstraction and source/provenance schema.
- Official API adapters where access is available.
- Trend evidence collection and competitor comparison templates.

### 0.3 — Creative operations
- Structured content brief schemas.
- Brand strategy and campaign output templates.
- Design brief generator and creative QA checklists.

### 0.4 — MCP server
- Read-only trend research and campaign knowledge tools.
- Authentication, permission scopes, rate limiting and audit logs.
- Integration tests against supported MCP clients.

### 0.5 — Learning loop
- Campaign result import, baseline normalization and experiment registry.
- Score calibration reports with sample-size and confidence warnings.

### 1.0 — Stable release
- Versioned skill bundles and compatibility matrix.
- Security review, reproducible release artifacts and complete examples.

## Release gate
Do not mark a platform adapter as supported until installation, tool invocation, error handling and permissions have been tested in that platform's current environment.
