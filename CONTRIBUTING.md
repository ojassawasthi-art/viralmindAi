# Contributing

1. Open an issue describing the use case, evidence and expected behavior.
2. Keep skills modular and use progressive disclosure: concise `SKILL.md`, deeper material in `references/`.
3. Cite official platform documentation for claims about platform rules or ranking systems. Label creator observations as observations and unverified claims as hypotheses.
4. Never add credentials, private analytics exports or personal data to commits.
5. Add or update tests for code changes; run `python -m unittest discover -s tests -v`.
6. Keep outputs honest: no guaranteed views, followers, revenue or virality.

By contributing, you agree that your contributions are provided under the repository's MIT license.
